音效版 Soundboard 使用說明（版本 0.2）
================================

無須安裝 Python，完成下列三個步驟即可使用。


【第 1 步】安裝虛擬音源線（僅需一次）

  Windows 不允許程式直接將聲音送入麥克風，因此需要免費的 VB-CABLE：
  1. 至 https://vb-audio.com/Cable/ 下載「VB-CABLE Driver」
  2. 解壓縮後，在 VBCABLE_Setup_x64.exe 上按右鍵 →「以系統管理員身分執行」→ Install Driver
  3. 重新開機
  4. 重要：安裝後 Windows 可能將「CABLE Input」設為預設播放裝置。
     請至「設定 → 系統 → 音效 → 輸出」將預設裝置改回耳機，
     否則遊戲與音樂的聲音也會被通話對象聽到。


【第 2 步】放入音效並啟動程式

  1. 將音效檔（.ogg .mp3 .wav .flac .opus .aiff 等）放入「音效」資料夾
     （也可在程式中按一下「📁 選擇資料夾」使用其他資料夾）
  2. 按兩下 Soundboard.exe
     ※ 第一次開啟時若顯示「Windows 已保護您的電腦」，請按「其他資訊 → 仍要執行」
       （原因是程式沒有付費的數位簽章，並非病毒）
  3. 按一下左側的「⚙ 設定」，在「🎧 音訊裝置」確認：
       🎧 監聽裝置（耳機／喇叭） → 耳機
       🎙 虛擬麥克風輸出         → CABLE Input (VB-Audio Virtual Cable)（通常會自動選取）
       🗣 實體麥克風             → 平常使用的麥克風
     首頁上方顯示黃色橫幅「尚未設定虛擬麥克風」時，表示通話對象聽不到音效，
     請按一下橫幅上的「前往設定 →」處理。


【第 3 步】設定 Discord

  使用者設定 → 語音與視訊：
    輸入裝置 → CABLE Output (VB-Audio Virtual Cable)
  請務必關閉「雜訊抑制」（Krisp 與標準皆需關閉）與「自動判斷輸入靈敏度」，
  否則音效與混音器的聲音會被 Discord 濾除（使用語音啟動時，請手動調低靈敏度）。
  鍵盤聲等雜音改由音效版的「🔇 麥克風降噪」處理（預設為「標準」，鍵盤聲較多時可選「強」）。


【介面】

  左側導覽列可切換「🏠 首頁」「🖼 貼圖」「⏺ 回放錄音」「🎚 混音器」「⚙ 設定」：
    首頁      音效按鈕、搜尋與常用按鈕（選擇資料夾、新增群組、快速鍵、浮動視窗、試聽、全部停止）
    貼圖      貼圖縮圖牆，按一下就複製，到 Discord 按 Ctrl+V 傳送（見下方【貼圖】）
    回放錄音  持續錄製多個來源（我的麥克風、Discord、YouTube 等）最近數分鐘的聲音，
              按一下「擷取」分軌儲存，再剪輯成新音效
    混音器    所有音量皆於此調整（總音量、音效、麥克風、監聽），
              也可將 Chrome、Spotify 等程式的聲音傳送給通話對象
    設定      音訊裝置、麥克風降噪與測試、進場音效、開機與背景執行、語言、關於（變更會自動儲存）
  左下角的「狀態」區：虛擬麥克風是否運作中、Discord 語音狀態、試聽模式與回放錄音狀態。


【操作】（於首頁）

  左鍵              傳送給通話對象並監聽（按鈕顯示為藍色）
  Shift＋左鍵       試聽：僅本機播放，通話對象聽不到（按鈕顯示為綠色）
  🎧 試聽 / Ctrl+P  開啟試聽模式後，左鍵也僅在本機播放
  右鍵              播放、試聽、設定全域快速鍵、加入浮動視窗、設為進場音效、
                    重新命名（同時修改檔名）、編輯／後製、在檔案總管中顯示、刪除音效、移到群組
  Ctrl＋左鍵        複選多個音效，再按右鍵選擇「🗂 移到群組」一次移入群組；按 Delete 一次刪除
  🗑 刪除音效       右鍵 →「🗑 刪除音效…」：確認後檔案移至資源回收筒（可還原），相關設定一併移除
  🗂 新增群組       建立群組（搞笑、恐怖等）；按一下群組標題可收合，按右鍵可重新命名、上移／下移、刪除
  拖曳音效          按住音效拖曳至群組標題後放開，即可移入該群組；拖曳至其他音效上可調整順序
  拖曳群組標題      上下拖曳可調整群組順序（藍線表示插入位置；搜尋時無法拖曳）
  浮動視窗 ◀ ▶      切換浮動視窗顯示的群組（📌 釘選的音效／各群組）
  🚪 進場音效       右鍵 →「🚪 設為進場音效」，加入 Discord 語音頻道時自動播放給通話對象
                    （開關、延遲與試播位於「⚙ 設定 → 🚪 進場音效」）
  🔇 麥克風降噪     位於「⚙ 設定」：僅處理麥克風聲音，不影響音效；鍵盤聲較多時請選「強」（未說話時完全靜音）
  🎙 麥克風測試     位於「⚙ 設定」：檢視原音與降噪後的波形，錄製一段聲音交替播放比較（僅本機監聽）
  ⌨ 快速鍵          檢視及設定所有快速鍵（遊戲中也能使用）
                    建議使用 Ctrl+Alt+數字、數字鍵盤或 F13–F24，避免使用遊戲的操作鍵
  🪟 浮動視窗       螢幕角落的半透明音效版：拖曳標題列可移動，按 ⋮ 可調整不透明度
                    （遊戲請使用「無邊框視窗」模式，獨佔全螢幕會遮住浮動視窗）
  Esc               全部停止
  音量              全部於「🎚 混音器」調整：總音量、音效（通話對象聽到的）、麥克風、監聽（0–200%）
                    單一音效的音量請使用右鍵選單的「✂ 編輯／後製…」


【貼圖】（按一下複製，到 Discord 按 Ctrl+V 傳送）

  1. 「📁 選擇資料夾」指向貼圖資料夾（例如 LINE 貼圖下載器的輸出，一個子資料夾視為一個系列），
     或「➕ 匯入貼圖」複製檔案進來（貼圖很多時建議直接選擇資料夾，不必匯入）
  2. 左鍵按一下貼圖即複製到剪貼簿，到 Discord 輸入框按 Ctrl+V 傳送（PNG、GIF 都可以，GIF 貼上後仍會動；
     APNG、WebP 動態貼圖會自動轉成 GIF）
  3. 關鍵字：貼圖按右鍵「🏷 編輯關鍵字…」，輸入「早安, 你好」等字詞；之後在搜尋框打「早安」，
     這張貼圖就會出現在最上方的「💡 關鍵字」區
  4. 文字貼圖：LINE 的訊息貼圖與「隨你填」名字貼圖集中在標題有 ✏ 的區塊，在搜尋框打字就會直接
     套用到這些貼圖上，按一下即複製套好字的貼圖（舊版下載器抓的系列，請用新版再下載一次）
  - 右鍵：複製、✏ 輸入文字後複製、📤 用 Webhook 傳送、🏷 編輯關鍵字、在檔案總管中顯示、刪除
  - 「貼圖大小」可把貼圖縮小後再複製或傳送（較像表情貼、檔案也較小）
  - 用 Webhook 傳送（選用）：在 Discord 頻道「⚙ 編輯頻道 → 整合 → Webhook → 新 Webhook → 複製 Webhook 網址」，
    再到音效版「⚙ Webhook 設定…」貼上網址並儲存。之後可用右鍵傳送貼圖，或在上方文字框輸入文字、
    按 Enter 傳送純文字訊息（以 Webhook 的名稱發送，不會觸發 @everyone）
  - Webhook 網址等同頻道的發言密碼，只存在你電腦的設定檔，請勿分享給別人
  - 貼圖著作權屬於原作者，請僅限個人使用


【混音器】（將 Chrome、Spotify 的聲音傳送給通話對象）

  1. 先讓程式發出聲音（例如以 Chrome 播放 YouTube）
  2. 「🎚 混音器」→「＋ 加入程式」選擇該程式（未顯示時按一下 🔄）→ 加入
  3. 通道顯示「● 傳送給對方」即完成；程式關閉後重新開啟會自動連接
  - 每條通道：推桿（滾輪微調、按兩下恢復 100%）、音量表、靜音、✕ 移除
  - 總音量、音效、麥克風、監聽也在此調整；除「監聽」外，靜音僅影響通話對象聽到的聲音
  - 無法加入 Discord（會產生回音）；需要 Windows 10 2004 或以上版本


【開機自動啟動與背景執行】

  「⚙ 設定 → 🖥 開機與背景執行」：
     - 開機時自動啟動音效版（登入 Windows 後於背景啟動）
     - 開機啟動時不顯示視窗，僅顯示於右下角系統匣
     - 按一下 ✕ 關閉視窗時縮小至系統匣（預設開啟）：快速鍵、浮動視窗與進場音效照常運作
  系統匣圖示：按一下開啟主視窗；按右鍵可選擇顯示音效版、浮動視窗、試聽模式、全部停止、結束音效版
  完全結束程式：系統匣圖示右鍵 →「結束音效版」，或設定頁的「⏻ 結束音效版」
  已在背景執行時再次開啟 Soundboard.exe，會顯示原本的視窗，不會啟動第二個


【語言】

  「⚙ 設定 → 🌐 語言」的「介面語言」可選擇：跟隨系統、繁體中文、English、日本語、한국어
  變更後會詢問是否立即重新啟動（需重新啟動音效版才會套用）。
  「⚙ 設定 → ℹ 關於」可查看版本與設定檔位置，按「📂 開啟設定資料夾」可開啟該資料夾。


【編輯音效】（各音效音量不一致時）

  右鍵音效 →「✂ 編輯／後製…」
     - 音量：使用滑桿或直接輸入 dB 值（-80～+80），「✨ 自動」可調整至一般音效的音量
     - 「💾 將音量套用至此音效」：之後播放時皆使用此音量（原始檔案不變）
     - 僅保留中間一段：拖曳藍色邊線，或一邊試聽一邊按 I／O；可加入淡入淡出
     - 「➕ 儲存為新音效」或「⬇ 另存檔案…」（ogg / mp3 / wav / flac）


【回放錄音】（將通話對象剛才說的話剪輯成音效）

  1. 「⏺ 回放錄音」頁 → 開啟「開啟即時回放錄音」
  2. 勾選錄音來源（可同時勾選多個）：🎙 我的麥克風、Discord.exe、chrome.exe（YouTube）等
     未勾選的程式完全不會被錄製
  3. 選擇「保留長度」（預設 3 分鐘，僅保留於記憶體，較舊的內容自動捨棄）
  4. 按一下「⏺ 擷取最近 3 分鐘」（或設定快速鍵「⏺ 擷取回放錄音」）→ 每個來源分別儲存為一條音軌
  5. 在片段上按「✂ 編輯」：
     - 按一下波形：移動播放頭（黃線）；黃線可直接拖曳（播放中也可以）
     - 拖曳藍色邊線：調整要保留的開頭／結尾；Shift＋拖曳：重新選取範圍
     - Ctrl＋滾輪：放大縮小；放大後拖曳空白處可左右平移畫面
     - 空白鍵：從播放頭播放／暫停　I／O：將播放頭位置設為選取範圍的起點／終點
     - 各音軌可開關（例如不需要 YouTube 的背景音樂）、調整音量（已自動放大）、🔇 降噪
       放大音量時峰值會被平滑壓制，不會破音；波形變為紅色才表示壓縮過度
     - 淡入／淡出
     - 按「➕ 儲存為新音效」即會出現在首頁；也可按「⬇ 另存檔案…」存為 ogg / mp3 / wav / flac
  ※ 錄到的聲音較小屬正常現象（錄製的是調整音量前的聲音），編輯器會自動放大
  ※ 資源用量低：每個來源約使用 0.3% 單一核心 CPU，3 分鐘約 33 MB 記憶體
  ※ 需要 Windows 10 2004 或以上版本；預設為關閉，錄製他人聲音前請先取得同意


【常見問題】

  通話對象聽不到音效   → Discord 輸入裝置需選擇 CABLE Output，並關閉 Krisp
  通話對象聽不到說話聲 → 於「⚙ 設定」開啟「將麥克風聲音混入虛擬麥克風」，並選擇正確的「🗣 實體麥克風」
  本機聽不到音效       → 於「⚙ 設定」的「🎧 監聽裝置」選擇耳機，且「🎚 混音器」的「🎧 監聽」不可為 0 或靜音
  找不到喇叭／耳機     → 接上後稍候數秒即會自動出現；若未出現請按「⚙ 設定 → 🔄 重新偵測裝置」
  進場音效未播放       → 僅在「加入」語音頻道的當下播放；啟動程式時已在語音頻道中，請離開後重新加入
  通話對象聽到鍵盤聲   → 降噪選擇「強」，並以「🎙 麥克風測試」錄製一段確認
  遊戲中快速鍵沒有反應 → 改用其他按鍵組合；若遊戲以系統管理員身分執行，Soundboard.exe 也需以系統管理員身分執行
  .m4a / .wma 未顯示   → 這些格式需要另外安裝 ffmpeg（winget install Gyan.FFmpeg），
                         或先轉換為 .mp3 / .ogg
  混音器的程式聽不到   → 通道需顯示「● 傳送給對方」；確認總音量與該通道未靜音
  按 ✕ 後程式未結束    → 程式已縮小至右下角系統匣；請在圖示上按右鍵 →「結束音效版」
  介面語言未改變       → 變更語言後需重新啟動音效版
  程式發生錯誤         → 錯誤紀錄位於 %APPDATA%\Soundboard\soundboard.log
                         程式異常結束時，重新開啟後請查看同資料夾的 soundboard.prev.log
