# 貼圖關鍵字工具

為整個貼圖資料夾產生「打字跳出貼圖」用的關鍵字。音效版貼圖頁的搜尋框會讀這些關鍵字：打「早安」，有這個關鍵字的貼圖就排在最上面。

## 為什麼要自己產生

LINE App 打字跳出貼圖用的是每張貼圖的隱藏關鍵字，但這份資料**拿不到**：

- 從 LINE 下載的貼圖檔只有圖片（`NNN.png`、`NNN.gif`），沒有文字資料。
- 關鍵字存在登入後的 LINE App 裡，沒有公開下載的地方。

所以改用「看圖寫關鍵字」：先把一組貼圖拼成總覽圖，再由人或 AI 看圖寫出圖上的字和使用者可能會打的字。

## 每張貼圖的兩種文字

| 欄位 | 意思 | 例子 |
|---|---|---|
| `t` | 圖上寫的字，沒有字就留空 | `哩賀~` |
| `k` | 關鍵字：白話翻譯、同義詞、英文、情緒或場合（3～7 個） | `你好`、`哈囉`、`嗨`、`hi`、`打招呼`、`哩賀` |

一組貼圖一個檔案 `<組id>.json`。組 id 是系列資料夾名稱最後一個底線後面的部分，例如 `胖鯊魚鯊西米-嘿嘿嘿_32292384` 的組 id 是 `32292384`：

```json
{
 "001": {"t": "你阿嬤腳好!", "k": ["腳好", "很好", "讚", "厲害"]},
 "002": {"t": "哩賀~", "k": ["你好", "哈囉", "嗨", "hi", "打招呼", "哩賀"]},
 "003": {"t": "", "k": ["生氣", "哼"]}
}
```

這個格式與 LINE 貼圖鍵盤 App 的 `tools/keywords/<組id>.json` 相同，兩邊的檔案可以直接共用。

## 最簡單：用 Claude API 自動產生

有 Claude API 金鑰時，不必手動走下面的步驟：

- **新下載的貼圖**：在 [LINE 貼圖下載器](../line_sticker_dl) 的「AI 關鍵字」設定金鑰並勾選「下載完自動產生關鍵字」，下載完就有關鍵字。
- **以前下載的資料夾**：下載器按「為資料夾補關鍵字…」，或用指令列：

  ```powershell
  python tools/sticker_keywords/sticker_keywords.py generate "$env:USERPROFILE\Downloads\LINE貼圖"
  ```

  會先列出要處理幾組、幾張與預估費用，輸入 `y` 才開始；`--model claude-haiku-5-5` 可改用其他模型，`--yes` 不詢問。

預設模型是 Sonnet 5.5，一組 40 張約 US$0.03～0.05。已經有關鍵字的貼圖不會重做，手動改過的會保留。
金鑰與模型的說明見[下載器的 README](../line_sticker_dl/README.md#ai-關鍵字選用需要-claude-api-金鑰)，程式在 `keyword_ai.py`。

## 手動步驟

以下的 `LINE貼圖` 是 LINE 貼圖下載器的輸出資料夾，系列放在根目錄或作者資料夾底下都可以。

### 1. 拼總覽圖

```powershell
python tools/sticker_keywords/sticker_keywords.py sheets "$env:USERPROFILE\Downloads\LINE貼圖" out\sheets
```

- 每組一張 `<組id>.png`，每格左上角有紅色編號。超過 42 張的組會分頁（`<組id>_p2.png`）。
- 灰色底，白色的字也看得清楚。動態貼圖取第一格。
- 另外寫一份 `index.json`，列出每組的組 id、名稱、貼圖編號與總覽圖檔名。
- 加上 `--only-missing` 只拼還沒有關鍵字檔的系列，新增貼圖時用。

### 2. 看總覽圖寫關鍵字

對著總覽圖，為每張寫：

- **`t`**：照圖上的字寫。直排的字照閱讀順序寫，例如「你阿嬤腳好!」。
- **`k`**：3～7 個「使用者可能會打的字」，可以從這幾個方向想：
  - **白話翻譯**：台語、火星文、諧音翻成一般寫法。例如「跨啥小」→「看什麼」，「歹勢」→「不好意思」。
  - **同義詞**：「謝謝」→「感恩、謝啦、多謝」。
  - **英文**：`ok`、`hi`、`thanks`、`good night`。
  - **情緒或場合**：圖上沒字的貼圖靠這個，例如「生氣」、「哭哭」、「晚安」、「打招呼」。

貼圖很多時可以交給 AI（例如 Claude）看圖寫：把總覽圖分成幾批，平行處理。一組 40 張大約一張總覽圖。

### 3. 裝進貼圖資料夾

```powershell
python tools/sticker_keywords/sticker_keywords.py install "$env:USERPROFILE\Downloads\LINE貼圖" out\keywords
```

- 每個 `<組id>.json` 會存成對應系列資料夾的 `sticker_keywords.json`，跟著貼圖資料夾走。
- 已經有 `sticker_keywords.json` 時會**合併**：新檔案有的貼圖覆蓋，沒有的保留。加上 `--overwrite` 改為整個取代。
- 找不到對應系列的檔案會列出來。

回到音效版的貼圖頁按「🔄 重新整理」即生效。

### 4. 檢查進度

```powershell
python tools/sticker_keywords/sticker_keywords.py status "$env:USERPROFILE\Downloads\LINE貼圖"
```

列出還沒有關鍵字的系列與缺少的編號，最後一行是總張數與有關鍵字的張數。

## 音效版怎麼比對

1. 搜尋文字和關鍵字都先整理：去掉標點、符號和空白，英文轉小寫，所以 `OK`、`ok`、`Ok!` 都一樣。
2. 每張貼圖拿 `t` 和每個 `k` 比，取最高分。比中 `t` 再加 10 分，讓「圖上真的寫這個字」的貼圖排前面。

| 情況 | 分數 | 例子 |
|---|---|---|
| 完全相同 | 100 | 打「晚安」，關鍵字「晚安」 |
| 打的字以關鍵字結尾（關鍵字至少 2 字） | 60 + 關鍵字字數×2 | 打「好啦再見」，關鍵字「再見」 |
| 關鍵字以打的字開頭（打的字至少 2 字） | 50 | 打「再見」，關鍵字「再見啦」 |
| 關鍵字包含打的字（打的字至少 2 字） | 40 | 打「放假」，關鍵字「等待放假」 |
| 打的字包含關鍵字（關鍵字至少 2 字） | 30 + 關鍵字字數×2 | 打「今天好累喔」，關鍵字「好累」 |

只打一個字時必須完全相同才算，免得跳出一大堆不相關的貼圖。

除了 `sticker_keywords.json`，貼圖上按右鍵「🏷 編輯關鍵字…」自己補的字詞，以及 LINE 訊息貼圖的預設文字，也會一起比對。

## 打某個字卻沒跳出想要的貼圖

在音效版那張貼圖上按右鍵「🏷 編輯關鍵字…」補上你打的字，馬上生效。也可以直接改系列資料夾裡的 `sticker_keywords.json`，改完按「🔄 重新整理」。用到哪補到哪，比一次全部重寫有效。
